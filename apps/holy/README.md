# Holy

The vibecoding platform by Holystic Labs. Build, publish, and monetize web apps using AI.

## Getting Started

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

## Configuration

Create a `.env.local` file:

```bash
# HolyOS API Configuration
NEXT_PUBLIC_HOLYOS_API_URL=https://api.holyos.io
HOLYOS_API_KEY=your_api_key_here
```

## Routes

- `/` — Landing page
- `/dashboard` — Dashboard overview
- `/dashboard/projects` — Project management
- `/dashboard/store` — Web App Store
- `/dashboard/analytics` — Analytics
- `/dashboard/revenue` — Revenue & rewards
- `/dashboard/settings` — Settings
- `/login` — Sign in
- `/register` — Sign up

## Tech Stack

- Next.js 16, React 19, TypeScript
- Tailwind CSS v4, shadcn/ui
- Jotai, Recharts, Geist fonts
