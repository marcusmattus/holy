# Holy Brand Assets

Design tokens and brand guidelines for the Holy platform by Holystic Labs.

## Colors

| Token              | Hex       | Usage                     |
| ------------------ | --------- | ------------------------- |
| `--holy-purple`    | `#7C3AED` | Primary brand color, CTAs |
| `--cosmic-blue`    | `#2563EB` | Secondary accent, HolyOS  |
| `--neon-emerald`   | `#10B981` | Success states, revenue   |
| `--deep-void`      | `#0A0A0F` | Dark background           |
| `--surface`        | `#18181B` | Card / panel backgrounds  |
| `--border-color`   | `#27272A` | Borders and dividers      |
| `--soft-halo`      | `#F8FAFC` | Light text / icons        |
| `--text-secondary` | `#A1A1AA` | Muted text                |

## Brand Architecture

- **Holy** — The product (vibecoding platform)
- **HolyOS** — The platform operating system (APIs, runtime, rewards)
- **Holystic Labs** — The company

## Logo

The Holy wordmark uses a simple square `H` icon in `#7C3AED` violet with rounded corners.

## Typography

- **Sans**: Geist Sans
- **Mono**: Geist Mono
